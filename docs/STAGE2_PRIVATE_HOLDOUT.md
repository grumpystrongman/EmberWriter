# Stage 2 private holdout scorer

Run locally in PowerShell: `Get-Content -Raw local-holdout.json | py -3.14 scripts/stage2_holdout.py`. The script reads stdin only, makes no network calls, and emits aggregate counts without questions or answers. Keep the input, private review records and source material outside Git. This tool does not invoke a model. Generate predictions locally and freeze the inventory before prediction; protect the labels from the system under test. The tool cannot enforce blindness or prove when the inventory was frozen.

Input is an object with `inventory`, `inventory_sha256` and `predictions`. The digest is SHA-256 of UTF-8 JSON serialized with sorted keys, no whitespace and unescaped Unicode (Python `digest` in the script). Preserve the digest independently before producing predictions. Each source in `inventory.sources` has unique `id`, `edition`, lowercase `sha256` of the immutable source bytes, positive `length` in the coordinate system used by citations, and positive integer `book`. Without optional byte verification the operator must independently check the hash and coordinate system against the local source.

Each item in `inventory.cases` has unique `id`, `question`, `origin: "author_reviewed"`, `review_reference`, `review_status: "approved"`, `lens` (`world_truth`, `character_belief`, or `reader_revelation`), and `as_of: [book, scene]` with positive integers. Character belief also requires `believer`. The `label` is `answer` with a nonempty `answer`, or `abstain` with `answer: null`. Each case requires at least one citation, including negative cases: `source_id`, matching `edition` and `source_sha256`, zero-based half-open `start` and `end`, and `reveal_at: [book, scene]` no later than the cutoff. Citations for negative cases identify the scope examined, not proof that absence is established. Event chronology and publication revelation may differ; humans must review this metadata.

Each prediction has the case `id`, a `label` and either its nonempty `answer` or null for abstention. All cases must have exactly one prediction. Accuracy is exact case-insensitive trimmed answer matching including correct abstentions; abstention rate is all abstentions divided by all cases. Negative-case count and correct abstentions are also reported. Paraphrases can be correct yet score as wrong. Source entailment is always null: coordinate validity is not entailment. No supplied identifier, signature string, hash, or count verifies a human, independent review, source content, semantic distinctness, or release eligibility. Fifty paraphrases can still pass text deduplication; independent review remains necessary. This tool never assigns a 5/5 or changes release policy.


## Optional local byte verification

Add `source_paths` to the input object, mapping every source ID exactly once to a local file path. For this mode, `length`, `start`, and `end` are byte counts, not characters or lines; each citation must also contain `span_sha256`, the lowercase SHA-256 of the exact half-open byte slice. The scorer reads each file locally, checks its full byte length and SHA-256, and checks every cited slice hash. A mismatch or missing file fails closed. Paths, bytes, questions, answers and citations are not printed; the command-line error is deliberately generic. Treat input, paths, hashes and aggregate output as sensitive: hashes can fingerprint known text, and shell history, redirects, crash reporting, backups and external processes are outside this tool's control. Do not commit them. No model or network is invoked. Verify trusted local files and access controls independently; this does not prove the correct edition was selected, its origin, chronology, or that a span supports a claim.

Predictions may include `citations`, a list of `{source_id, start, end}` objects. `citation_matches` counts answer-labeled cases where the prediction is also answer-labeled and supplies at least one citation, all of which exactly match predeclared citation coordinates. This count is separate from answer accuracy and does not require a correct answer or establish entailment; empty, invented, partial or extra citations do not count. Citation labels are author-supplied assertions, not independent proof. `similar_question_pairs` counts pairs with token-set Jaccard similarity at least 0.8 as a review signal; it neither detects all paraphrases nor establishes independent cases. Exact normalized duplicates are rejected. Repeated source hashes for the same book under different IDs are rejected, but aliases, altered files and fabricated provenance remain possible.

The inventory hash is an integrity checksum, not a timestamp or freeze-before-run attestation: an operator can modify both inventory and hash after prediction. For a meaningful blind protocol, independently preserve the digest with a trusted timestamp before prediction; isolate labels and review material from the system under test; retain reproducible local records of the model version, prompts, outputs and run order; and have independent humans review provenance, distinctness, answer correctness and citation support. This script cannot verify any of those controls or human identity or reading comprehension. Never send a private manuscript to a hosted model. This tool does not certify a release; the release policy still requires exact-commit machine evidence and independent author and expert signoffs.
