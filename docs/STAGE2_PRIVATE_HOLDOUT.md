# Stage 2 private holdout scorer

Run locally in PowerShell: `Get-Content -Raw local-holdout.json | py -3.14 scripts/stage2_holdout.py`. The script reads stdin only, makes no network calls, and emits aggregate counts without questions or answers. Keep the input, private review records and source material outside Git. This tool does not invoke a model. Generate predictions locally and freeze the inventory before prediction; protect the labels from the system under test. The tool cannot enforce blindness or prove when the inventory was frozen.

Input is an object with `inventory`, `inventory_sha256` and `predictions`. The digest is SHA-256 of UTF-8 JSON serialized with sorted keys, no whitespace and unescaped Unicode (Python `digest` in the script). Preserve the digest independently before producing predictions. Each source in `inventory.sources` has unique `id`, `edition`, lowercase `sha256` of the immutable source bytes, positive `length` in the coordinate system used by citations, and positive integer `book`. The operator must independently check the hash and coordinate system against the local source; the scorer never reads source bytes.

Each item in `inventory.cases` has unique `id`, `question`, `origin: "author_reviewed"`, `review_reference`, `review_status: "approved"`, `lens` (`world_truth`, `character_belief`, or `reader_revelation`), and `as_of: [book, scene]` with positive integers. Character belief also requires `believer`. The `label` is `answer` with a nonempty `answer`, or `abstain` with `answer: null`. Each case requires at least one citation, including negative cases: `source_id`, matching `edition` and `source_sha256`, zero-based half-open `start` and `end`, and `reveal_at: [book, scene]` no later than the cutoff. Citations for negative cases identify the scope examined, not proof that absence is established. Event chronology and publication revelation may differ; humans must review this metadata.

Each prediction has the case `id`, a `label` and either its nonempty `answer` or null for abstention. All cases must have exactly one prediction. Accuracy is exact case-insensitive trimmed answer matching including correct abstentions; abstention rate is all abstentions divided by all cases. Negative-case count and correct abstentions are also reported. Paraphrases can be correct yet score as wrong. Source entailment is always null: coordinate validity is not entailment. No supplied identifier, signature string, hash, or count verifies a human, independent review, source content, semantic distinctness, or release eligibility. Fifty paraphrases can still pass text deduplication; independent review remains necessary. This tool never assigns a 5/5 or changes release policy.
